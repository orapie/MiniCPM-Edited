# P1 排序诊断进展（2026-11-01）

本记录是 P1 的进展，**不是 P1 完成或精度验收通过的报告**。本次没有改变查询/索引的向量文本规则，没有更新索引，没有启用混合排序，也没有解决简繁转换、第三人称和无答案处理。

## 本次修改

- 对通过门槛的向量候选，记录片段余弦、场景父向量余弦、片段词项匹配率和原有最终向量分数。`RAG_TRACE` 中的 `candidateScores` 格式为 `id:chunk:parent:lexical:final`，`none` 表示不存在父向量。JSON trace 中对应 `vectorCandidateScoreDetails`。只记录分数和 ID，不记录原始问题或正文。此列表是 top-K 和 minScore 之后的结果，不能解释没有进入列表的候选；不改变现行排序权重。
- 同分时按片段 ID 排序，避免索引条目的排列影响候选顺序。记录词项分数仅为诊断，不影响排序或筛选。
- 增加 `scripts/evaluate_rag_rankers.py`，在同一索引、同一候选全集上对比现行分数和实验性加权得分；保持父场景去重并记录 top 20。结果是阈值之前的诊断排名，不能用作实际注入或角色知识授权结果。运行：

```sh
python3 scripts/evaluate_rag_rankers.py --index database/runtime/android/vector/index.json --output /tmp/rag-ranker-evaluation.json
```
