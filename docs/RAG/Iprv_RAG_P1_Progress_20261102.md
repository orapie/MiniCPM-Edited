# P1 资料选择与追踪进展（2026-11-02）

本次是 P1 的一部分，不是 P1 的完成验收。数据集、索引、向量算法、阈值和最终资料排序公式保持原样；不涉及简繁转换。

## 实现

- `CharacterRagPromptBuilder` 已经选定某句原文时，如果该句以问号结束，且预算允许，优先保留它后面最多两句，以便包括说话者描述及后续回答；总资料 600 字符、单条正文 130 字符的限制保持不变。若无法容纳两句则尝试一条，仍放不下则沿用已有预算行为。只依据连续原文，不引入模型生成的答案，不改变场景的授权或时间过滤。
- `RagContextDecision.selectedChunkSpans` 对实际保留句子记录相对于原检索片段的半开 UTF-16 范围。多个句子有多个范围，分隔换行是组装时添加的，不属于原始片段；它不是源文件行号，也不是已有 metadata 的 Unicode 码点偏移。普通 RAG、被过滤和未入选条目不一定有范围。
- `RAG_TRACE` 的每条 `contextDecisions` 附加 `spansUtf16`、`selectionBoost`、`selectionScore`。后两项分别是候选各句最大 `queryBoost` 和现行的 `vector score + queryBoost`；未参与角色资料排序时为 `none`。它们用于诊断，未改变分数公式。trace 不包含用户问题或资料正文。

## 验证与已知边界

- 合成问答样例验证后续回答保留、无关前句不被优先保留、预算、原始用户问题及片段范围可逆；真实数据库 `claim-evt-115@1329-1624` 使用与原文问句匹配的输入做定向片段测试，后续回答“您是面壁者”能保留。该测试直接提供了目标片段，**不是端到端召回验证**。
- 通过真实数据库完整编排再次检查“罗辑现在的身份是什么”时，当前算法仍把目标场景里的其他句子选入参考资料，并未保留“面壁者”。该检查暴露了候选与句子排序仍不足；本次不声称解决这个问题或总体准确率明显提高。
- 连续问答并不保证回答一定与玩家问题相同，也不能保证代词主体明确。问句后紧接两句的启发式可能保留不相关或无答案的内容；还需要独立、多角色、跨场景评估。
- 本次未能执行设备测试：ADB 可运行，但测试时设备列表为空。未更换模型、未安装 APK 或改动用户会话，也没有真实模型输出证据。
