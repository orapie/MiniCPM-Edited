# V2.2 阶段 2：BGE 语义检索工程说明

本阶段已完成工程接入和根目录数据包生成。按照本次要求，没有进行最终构建、设备端验证或检索质量评测，不能据此认定设备运行成功或检索准确率已有提升。

## 数据和查询路径

- 数据来源仍为根目录 `database/`。生成器从 V2.2 SQLite 的活动 `evidence_embeddings` 导出 536 条 512 维向量及对应来源信息到 `runtime/android/vector/bge_index.json`，不修改源 SQLite。
- 数据包内加入 `BAAI/bge-small-zh-v1.5` revision `7999e1d3359715c523056ef9478215996d62a620` 的 ONNX 模型、词表和模型清单；查询端使用 CLS pooling、L2 归一化、512 token 截断以及原索引所用查询前缀。
- 普通 RAG 和角色 RAG 在当前包提供 BGE 路径时使用 `bge_onnx`，每轮用当前问题生成查询向量。角色模式在向量排序前按来源范围和 cutoff 过滤；最终 prompt 仍经过原有参考资料及角色知识授权流程。
- 模型或查询执行失败不会静默降级为 hash；没有 BGE 路径的旧格式数据包保留其原有 hash 后端。不同维度向量不再截断比较。
- 模型与索引纳入包清单和生命周期；包变更后检索器随之重建。新包 fingerprint 为 `2c0b90db9383839146dbd703a4bd7ab2e74040760a31ba3549877d5130df5a53`，原有其他 fingerprint 的会话按现有规则保留并隔离。

## 仍未完成

本阶段的 Android 端到端运行、性能及检索效果均未验收。BGE 证据候选不自动成为角色已知事实；已审核事实仍由现有 V2 词项路径召回。阶段 3 随后已完成实验性词项和语义融合的工程接入；阶段 4 的完整设备验收未实施。
