### 阶段 2：角色卡映射与对话自然度

角色卡审计发现，五张现用卡都已有三条 `identity_core.speech_style`，均无 `speech_examples`。阶段 1 编译器只选前两条，且给所有角色填了同一句示例。新版使用最多三条有区别的表达习惯，缺少例句时留空。角色名称和别名仍作为身份锚点；世界观概述可能包含隐藏计划或后续事件，移出每轮角色提示。动机、原始价值观、心理、行为规则及第三方关系没有新增为常驻上下文，授权事实、门控、压缩和参考资料处理沿用原有路径。已有对话压缩按数据集版本、角色和截止点隔离，对话摘要在提示中仍仅用于承接。

对照使用已安装的阶段 1 版本与阶段 2 版本，均为 Character + RAG、`evt-125`、同一 MiniCPM5-2B 和 512 token 测试上限。选同题的责任态度和日常安慰，关闭 A 以控制标注变量。每题独立首轮，核对参考正文及 user 指纹。另跑阶段 1 的身份题和真实 A 成功组职业题，检查人称回归。没有固定采样种子，结论按小样本观察记录。贴合度以角色卡的措辞和回应方式评分，自然度以是否紧扣当前问句、表达是否顺畅评分，各 0–2 分。固定门控答复、保护重试和兜底另计。
