# Mem0

论文：Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory

- 作者：Chhikara et al.
- 时间：2025
- 预印本：[arXiv](https://arxiv.org/abs/2504.19413)
- PDF：[arXiv PDF](https://arxiv.org/pdf/2504.19413)

## 核心方法

Mem0 将长期记忆拆成从对话中提取、合并、更新和按需检索的独立流程，并比较了完整历史、普通 RAG 和结构化记忆。它关注的是“哪些内容值得长期保存”，而不只是把历史压短。

## 对本项目的适配

当前项目已经有 `ChatSessionStore`、`ConversationSummaryBuilder` 和 `MemoryStore`，因此最适合借鉴其分层思想：

- 短期上下文：当前问题和少量最近轮次。
- 角色记忆：稳定身份、关系和已确认剧情事实。
- 会话摘要：只保留后续对话需要的状态变化。
- 外部 RAG：只在当前问题需要时注入，不写入角色身份层。

这比简单扩大 `conversationSummary` 更适合端侧，也能降低每轮重新处理 system prompt 的输入量。

## 可行性

- 可行性：高。
- 适合位置：`ConversationSummaryBuilder`、`MemoryPromptSelector`、`CharacterPromptCompiler`。
- 主要风险：端侧自动写入记忆可能把模型幻觉保存为事实；必须保留来源、置信度、story cutoff 和角色可见性。
- 优先级：P1，适合作为上下文控制的长期记忆层。
